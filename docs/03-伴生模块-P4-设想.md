# 伴生模块 P4 实现说明：分享 / 导出卡片

| 项目 | 内容 |
| --- | --- |
| 模块编号 | P4 |
| 模块名称 | 分享 / 导出卡片（学习卡片分享器） |
| 强制技术点 | Intent、FileProvider、位图 |
| 实现形态 | 主 App 内独立模块（`export/` 包），首页两个入口触发 |
| 状态 | 已实现并实测 |

## 一、定位

主 App 回答「今天该复习哪些词」，伴生模块回答「我的学习状态怎么给别人看」。

它只做两件具体的事：

1. 把学习统计画成一张 1080×1440 的图片卡片，调起系统分享面板发出去；
2. 把词库与复习数据导出成 CSV，可以分享给其他 App，也可以「另存为」到用户选定的位置。

不做编辑、不做模板市场、不做社交，但每个环节都真的跑通：图片能在微信里打开，CSV 能在 Excel 里正确显示中文。

## 二、满足「伴生模块最低标准」的说明

| 标准 | 现状 |
| --- | --- |
| 可独立启动或从主屏 / 系统入口触发 | 从主 App 首页两个按钮触发（P4-01、P4-02 两个入口）；**未做独立 APK 与桌面图标**，属于从主入口触发 |
| 能读写主 App 数据 | 与主 App 同进程，直接读取 `WordRepository` 的统计数据与词库 |
| 有基本异常处理 | 文件写入失败、保存目标无法打开会抛出并提示；**分享目标预检（`queryIntentActivities`）尚未做** |
| 在 Git 中独立可追溯 | 代码集中在 `export/` 目录，提交记录按模块写清改动 |

## 四、技术实现要点

### 1. 位图生成

```
Bitmap.createBitmap(1080, 1440, ARGB_8888)
Canvas → 背景 #F2F4FA
       → 顶部 LinearGradient（#3F6BE0 → #7A5CE0）高 520
       → 「学习报告」+ 日期
       → 正确率 120sp 大字
       → 白色圆角卡片装四项统计（总词数 / 已学习 / 已掌握 / 待复习）
       → 底部标语
```

用原生 Canvas 而不是截屏：截屏受屏幕密度与状态栏影响，输出不稳定；Canvas 绘制在任何设备上结果一致。

### 2. FileProvider

```xml
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

`file_paths.xml` 只放行缓存目录下的 `share/` 子目录，不暴露根目录。

### 3. 分享 Intent

```kotlin
Intent(Intent.ACTION_SEND).apply {
    type = "image/png"        // 或 "text/csv"
    putExtra(Intent.EXTRA_STREAM, contentUri)
    addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
}
→ Intent.createChooser(...).also { context.startActivity(it) }
```

Android 7.0 起禁止跨 App 传 `file://`，所以全程只用 `content://`。

### 4. 另存为

`ActivityResultContracts.CreateDocument("text/csv")` 拿到用户选定 URI 后，用 `contentResolver.openOutputStream` 写入，不需要存储权限。

## 五、验收演示脚本（3 分钟内的模块段落）

1. 首页点「分享报告图」→ 系统分享面板弹出，选微信发送（证明位图 + Intent + FileProvider）；
2. 打开微信查看图片，统计数字与首页一致（证明数据同源）；
3. 回到 App 点「分享 / 导出 CSV」→ 选「保存到本地」→ 选保存位置（证明 SAF 写入）；
4. 在 Excel / WPS 打开该 CSV，中文释义不乱码（证明编码与转义）；
5. 把该 CSV 再通过「导入词库」读回，重复词被跳过（证明解析与去重闭环）。

## 六、与课程要求的差距

1. 没有独立 APK 与桌面图标，属于「从主入口触发」而非「独立启动」；
2. 分享前没有 `queryIntentActivities` 预检，无分享目标时依赖系统兜底；
3. 缓存文件未做定期清理，长期使用会在 `cache/share` 下累积；
4. 卡片未加学号姓名水印，录屏交付前需要补。

以上四项在下一轮迭代补齐。
