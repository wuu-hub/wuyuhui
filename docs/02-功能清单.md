# 主 App 功能清单（B4 单词记忆）

> 本清单用于选题审核：按模块列出功能、优先级与验收方式。P0 为最低要求（必须完成），P1 为完成度加分项，P2 为时间富余时再做。

## 一、界面与导航

```
底部导航：今日 ｜ 词库 ｜ 测试 ｜ 统计
今日 ──→ 复习流程（逐词卡片）
词库列表 ──→ 词库详情 ──→ 词条详情
词库列表 ──→ 导入词库（文件选择）
测试 ──→ 测试结果页
统计 ──→ 分享 / 导出（伴生模块入口）
```

| 编号 | 界面 | 核心内容 | 优先级 |
| --- | --- | --- | --- |
| UI-01 | 今日 | 今日到期数、连续学习天数、开始复习按钮、到期词库分布 | P0 |
| UI-02 | 词库列表 | 词库卡片（名称、词数、到期数）、新建、导入 | P0 |
| UI-03 | 词库详情 | 词条列表、搜索、按到期时间 / 字母排序、批量操作 | P0 |
| UI-04 | 词条详情 | 单词、释义、例句、复习历史、下次复习时间、手动调整 | P0 |
| UI-05 | 复习 | 卡片翻面、四档自评、进度条、跳过与收藏 | P0 |
| UI-06 | 测试 | 拼写题与选择题、计时、提交判分 | P0 |
| UI-07 | 测试结果 | 得分、错题列表、错词一键加入重点复习 | P0 |
| UI-08 | 统计 | 复习量、正确率、连续天数、未来 7 天到期预测 | P1 |
| UI-09 | 设置 | 每日新词上限、提醒时间、通知开关、词库导出入口 | P1 |

## 二、数据与持久化

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| DB-01 | 词库表 `WordLibrary` | 名称、来源、创建时间、词数统计 | P0 |
| DB-02 | 词条表 `Word` | 拼写、释义、例句、音标、`intervalIndex`、`nextReviewAt`、`easeFactor`、`lapses`、`isStarred` | P0 |
| DB-03 | 复习记录表 `ReviewLog` | 词条 ID、复习时刻、自评档位、作答耗时 | P0 |
| DB-04 | 外键与索引 | 词库→词条外键；`nextReviewAt` 建索引供到期查询 | P0 |
| DB-05 | 数据库迁移 | 至少完成一次 `Migration`，版本号可从 1 升到 2 | P1 |
| DB-06 | DataStore 设置 | 每日新词上限、提醒时间、连续天数、上次学习日期 | P0 |

## 三、核心算法（自定义业务逻辑）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| ALG-01 | 基础间隔序列 | 10 档间隔：5 分钟 / 30 分钟 / 12 小时 / 1 天 / 2 天 / 4 天 / 7 天 / 15 天 / 30 天 / 60 天 | P0 |
| ALG-02 | 四档自评调度 | 忘记 → 回退到 0 档；模糊 → 原地重复；想起 → 前进一档；熟练 → 前进两档 | P0 |
| ALG-03 | 难度因子 `easeFactor` | 初始 2.5、下限 1.3，按作答结果上下调整，放大或缩小实际间隔 | P0 |
| ALG-04 | 逾期补偿 | 逾期词条按逾期天数折算补偿间隔，避免积压一次性爆发 | P0 |
| ALG-05 | 到期队列生成 | 按 `nextReviewAt` 升序取当日到期词，按每日上限截断 | P0 |
| ALG-06 | 单元测试 | 用 JUnit 覆盖四档自评、逾期补偿、边界（首学、熟练封顶） | P0 |
| ALG-07 | 新词投放策略 | 每日新词上限内优先投放未学过的词，与到期复习量做配比 | P1 |

## 四、词库导入

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| IMP-01 | CSV 导入 | SAF 选择文件，列格式 `word,meaning,example`，首行可带表头 | P0 |
| IMP-02 | 校验与报错 | 逐行校验，格式错误定位到行号并可跳过该行继续导入 | P0 |
| IMP-03 | 去重合并 | 同一词库内按拼写去重，重复词不重复入库 | P0 |
| IMP-04 | 内置示例词库 | 首次启动提供一份示例词库，保证空态下有可操作路径 | P1 |
| IMP-05 | JSON 导入 | 支持结构化 JSON 词库 | P2 |

## 五、复习与测试

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| REV-01 | 卡片式复习 | 先只显示单词，翻面显示释义，再出现四档自评按钮 | P0 |
| REV-02 | 会话进度与中断恢复 | 记录当前会话位置，退出后可继续 | P1 |
| REV-03 | 收藏 / 重点标记 | 标星词条进入独立「重点」筛选 | P1 |
| QUIZ-01 | 拼写题 | 给出释义，输入拼写，按编辑距离判分 | P0 |
| QUIZ-02 | 选择题 | 四选一，干扰项从同词库其他词条抽取 | P0 |
| QUIZ-03 | 题量不足保护 | 词库少于 4 个词条时提示不可测试，避免生成异常题目 | P0 |
| QUIZ-04 | 结果反馈 | 得分、错题清单、错词自动回退到低档间隔 | P0 |

## 六、后台任务与提醒（硬能力落点）

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| BG-01 | WorkManager 周期任务 | 每日一次，计算当天到期词数并触发通知 | P0 |
| BG-02 | 通知渠道 | 独立渠道，标题携带到期词数 | P0 |
| BG-03 | 通知权限降级 | 拒绝通知权限后不发通知，首页横幅替代，设置页保留开启入口 | P0 |
| BG-04 | 逾期重排任务 | 长时间未打开 App 时批量重算 `nextReviewAt` | P1 |
| BG-05 | 任务约束 | 用约束条件避免低电量下执行重任务 | P1 |

## 七、三态与异常

| 编号 | 场景 | 加载态 | 空态 | 错误态 |
| --- | --- | --- | --- | --- |
| ST-01 | 词库列表 | 骨架屏 | 引导导入 / 新建 | 读取失败 + 重试 |
| ST-02 | 词库详情 | 列表骨架 | 空词库提示 | 查询失败 + 重试 |
| ST-03 | 今日 | 数字占位 | 无到期词 + 去学新词 | 计算失败提示 |
| ST-04 | 导入 | 进度指示 | 文件为空 | 行级错误提示 |
| ST-05 | 测试 | 生成中提示 | 词条不足 | 生成失败可重试 |

## 八、代码组织

```
com.wuyuhui.wordmemo
├── data/
│   ├── local/        Room 实体、DAO、数据库、迁移
│   ├── repository/   仓库层，聚合 Room 与 DataStore
│   └── importer/     CSV 解析与导入
├── domain/
│   ├── scheduler/    艾宾浩斯调度算法（纯函数，可单测）
│   └── stats/        统计计算
├── ui/
│   ├── theme/        主题
│   ├── today/        今日
│   ├── library/      词库列表、详情、词条详情
│   ├── review/       复习
│   ├── quiz/         测试
│   └── stats/        统计
├── work/             WorkManager 任务与通知
└── MainActivity.kt
```

分层约定：UI 层不直接接触 DAO，必须经过 Repository；算法层不依赖 Android 框架，保证可单测。
